Frequently Asked Questions
How does Phase 1 work without a backend?
ClientFlow uses the approved Vanilla JavaScript interface with a centralized repository that calls the NestJS REST API. Contacts, deals, tasks, and activities are persisted in the configured MongoDB workspace.
Can I drag and drop deals across pipeline stages?
Yes! In the Sales Pipeline page (deals.html), each deal card supports native HTML5 drag-and-drop between any of the 6 stages. You can also click the "Advance →" button for 1-click stage advancement.
How can I reset demo data if I make changes?
Development sample data is added safely with the documented API seed command. Production business data is never reset from the browser.
Where is data persisted?
Business data is stored by the API in MongoDB Atlas. The browser retains only an access token, a session summary, and harmless UI preferences; passwords and database credentials never reach browser JavaScript.
